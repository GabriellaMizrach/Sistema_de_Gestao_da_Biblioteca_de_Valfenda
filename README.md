# 🍃 Sistema de Gestão da Biblioteca de Valfenda

> *"O conhecimento é a maior das relíquias, e sua preservação, o mais nobre dos fardos."*

Bem-vindo ao repositório oficial do **SGBV**, o sistema automatizado de gestão de acervo e controle de circulação de tomos do Arquivo de Elrond. Este projeto foi concebido para substituir os antigos pergaminhos de controle manual, garantindo que nenhum mapa ou manuscrito histórico se perca durante as expedições da Sociedade do Anel e de outros viajantes.

---

## 📜 Funcionalidades do Acervo 

- **Catalogação de Tomos:** Cadastro, edição e consulta de obras raras, mapas e pergaminhos.
- **Credenciamento de Viajantes:** Registro de elfos, magos e membros de comitivas autorizados a realizar consultas.
- **Controle de Circulação:** Registro de retiradas (empréstimos) e devoluções, com validação de status de disponibilidade.
- **Auditoria e Relatórios:** Listagem em tempo real dos itens que encontram-se em posse de terceiros fora dos limites de Valfenda.

---

## 🛠️ Tecnologias Forjadas 

A arquitetura do sistema foi desenhada unindo metodologias ágeis e ferramentas modernas:

* **Linguagem:** Python 3.x, CSS, HTML.
* **Interface e Nuvem (Deploy):** Streamlit (Streamlit Community Cloud)
* **Prototipação (UI/UX):** Figma 
* **Banco de Dados:** SQLite / Modelagem Relacional (DER)
* **Engenharia de Software:** Diagramas UML, DFD, Casos de Uso e Dicionário de Dados padronizados.
